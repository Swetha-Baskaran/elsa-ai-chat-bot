# Elsa — AI Chat Assistant

Elsa is a simple AI-powered chatbot mobile application built with **React Native and Expo**. It provides a conversational interface where users can send messages and receive AI-generated responses through a chatbot API.

## Features

* Simple and intuitive chat interface
* Send messages and receive AI-generated responses
* API integration for chatbot functionality
* Built as a cross-platform mobile application using Expo

## Tech Stack

* **React Native**
* **Expo**
* **JavaScript**
* **RapidAPI**
* **ChatGPT API**

## API Integration

The application communicates with the chatbot service through RapidAPI.

**Endpoint:**
`https://chatgpt-api7.p.rapidapi.com/ask`

Requests are sent using JSON with the required RapidAPI authentication headers, and the API response is displayed in the chat interface.

## Getting Started

### Prerequisites

Make sure you have:

* Node.js installed
* Expo CLI / Expo development environment
* A RapidAPI account and API key

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Swetha-Baskaran/Chat-Bot.git
cd Chat-Bot
npm install
```

Start the Expo development server:

```bash
npx expo start
```

You can then run the application using an Android emulator, iOS simulator, or the Expo Go app.

## Project Purpose

This project was built to explore **React Native mobile development, API integration, asynchronous requests, and building conversational user interfaces**.
